# chrome-plugins

ThreeFish-AI 自研 Chrome 扩展集合（均为 unpacked 形态，开发者模式「加载已解压的扩展程序」安装）。

| 插件 | 说明 |
| :--- | :--- |
| [claude-tab-group-unifier](./claude-tab-group-unifier/) | 把 Claude in Chrome 扩展为每个 Agent 会话创建的标签组（✅Claude / ⌛Claude）收敛为唯一的 Claude 主组，解决组名硬编码与并行会话组膨胀（上游无官方配置：[anthropics/claude-code#72443](https://github.com/anthropics/claude-code/issues/72443)）；Tab Reuser 页签复用：Claude 访问已打开的 URL 时复用既有页签，不再重复开签 |
